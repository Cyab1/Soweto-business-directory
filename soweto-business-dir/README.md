# Soweto Business Directory 🌍

[![Django](https://img.shields.io/badge/Django-092E20?style=flat&logo=django&logoColor=white)](https://www.djangoproject.com/)
[![React](https://img.shields.io/badge/React-20232A?style=flat&logo=react&logoColor=61DAFB)](https://reactjs.org/)
[![PostgreSQL](https://img.shields.io/badge/PostgreSQL-316192?style=flat&logo=postgresql&logoColor=white)](https://www.postgresql.org/)

A full-stack directory platform connecting local businesses in Soweto with customers, built with modern web technologies.

![Screenshot of Application](screenshot.png) <!-- Add your screenshot -->

## ✨ Features

- **Business Listings** - Searchable directory with categories
- **Interactive Map** - Geolocation of registered businesses
- **Reviews & Ratings** - Community feedback system
- **JWT Authentication** - Secure user accounts
- **Responsive Design** - Mobile-friendly interface

## 🛠 Tech Stack

**Frontend:**
- React 18
- Redux Toolkit
- Bootstrap 5
- Leaflet Maps

**Backend:**
- Django 5
- Django REST Framework
- PostgreSQL
- JWT Authentication

``` bash
python manage.py runserver   
```
 ## Frontend Setup
 ```bash
cd frontend

npm start
```
